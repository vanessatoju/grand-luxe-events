# Grand Luxe Events

A polished, responsive event-venue website concept created as a fictional sales-demo project. It demonstrates how a premium Lagos event venue could present its spaces, packages, gallery and enquiry journey online.

> **Demo disclosure:** Grand Luxe Events is a fictional concept. The venue details, pricing, testimonials, contact information and imagery are illustrative and are not presented as verified information about a real business.

## Live Demo

https://grand-luxe-events-362bcj.v2.appdeploy.ai/

## Project Overview

The project is designed as a conversion-focused marketing website for an event venue. It combines editorial visual design with clear calls to action and interactive sections that guide visitors from discovery to a demo enquiry.

## Features

- Responsive desktop and mobile layouts
- Sticky navigation with mobile menu
- Hero section with venue-tour and WhatsApp demo CTAs
- Venue introduction and capacity highlights
- Event-type cards for weddings, corporate events and celebrations
- Three fictional venue spaces
- Facilities and feature presentation
- Filterable image gallery with lightbox interaction
- Fictional event packages and pricing
- Rotating sample testimonials
- Demo enquiry/availability form with validation and success state
- Expandable FAQ section
- Contact section with clearly marked placeholder details
- Repeated demo disclosures to prevent confusion with a real business website

## Technologies

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React icons
- Responsive CSS

## Testing

The repository includes a manual test plan in [`tests/tests.txt`](./tests/tests.txt) covering the primary sales journey, gallery filtering/lightbox behavior, enquiry validation, mobile navigation and the fictional-content safeguards.
